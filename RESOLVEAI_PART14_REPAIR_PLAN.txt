Run the REAL policy engine and compare its result with independent expectations.

REAL APPROVAL FLOW

2. Denied action does NOT execute.
3. Approval-required action does NOT execute before approval.
4. Approved action executes.
5. Duplicate execution using the same idempotency key does not create a duplicate side effect.

Verify database state after each case.
